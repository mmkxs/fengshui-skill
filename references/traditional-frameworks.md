# 传统流派与规则

## 形势与门床梁镜

依据入口、停留区、家具、梁柱、遮挡、开阔与围合组织布局讨论。以下是现代室内场景中常见的传统关注点，具体判断需说明采用的解释体系。它们的几何筛查参数由本工具公开记录，不能引用为古籍中的统一米制标准。

| 传统关注点 | 可核对的空间证据 | 本工具范围与缺项 |
| --- | --- | --- |
| 横梁压顶 | 梁体与停留区域的平面重叠、梁底到家具顶面/真实头部的竖向距离 | 计算 yaw-OBB 投影与净距。实际压迫感、梁的结构性质和使用姿态需现场核对 |
| 门冲床、门冲座 | 门洞平面、宽高、床/座位审查点高度、遮挡和日常使用状态 | 计算开口法向投影覆盖的单个点，搜索距离默认 6 m，可配置 |
| 镜照床、镜面正对门 | 镜面边界、反射面法向、真实眼位、遮挡物 | 计算审查点的镜面自反射路径，或门口眼位到床位的镜面反射路径。顶面中心代理点须注明 |
| 床头、座位有靠 | 真实头部/靠背点、朝后方向、同室墙体距离和高度 | 向标注墙体发射射线，默认最多搜索 3 m。空间布局中的方向不能由对称物品 OBB 唯一确定 |
| 门主灶 | 主入口角色、停留/居住空间、灶台与周边布局 | 门的几何位置不能自动确定主入口角色。灶口朝向和住宅坐向须确认 |
| 穿堂、藏风聚气 | 对外开口及中间空间、开合与遮挡、真实风和温差 | 先描述开口几何，再按传统体系讨论布局。空气流动计算读取独立通风证据 |

《宅经》与《葬书》用于术语、方位和形势概念溯源，《阳宅三要》用于门、主、灶与东四/西四宅、游年八宅的规则溯源，原文见 [classics/yangzhai-sanyao.md](classics/yangzhai-sanyao.md)（公有领域转录，夹有转录者补充内容，已在文件头标注）。现代镜面、室内家具尺寸与通风筛查是本工具的现代空间应用，报告避免伪造经典原文或把不同版本归并成唯一规则。来源入口见 [上游与来源](upstream.md)。

## 八宅与二十四山

八宅关注宅卦、命卦、方位以及门、主、灶之间的配置。先确认用户采用宅卦还是命卦口径，记录房屋坐向、主入口角色与参考北。宅向、门向、灶向、床头方向是不同字段，分别取证。

用户提供已确认 `compass.houseKua` 时，脚本返回该卦的八方位对照作为解读上下文。房间和家具的方位仍需依据实际空间与参考点确认。输入未提供宅卦时保留缺项。

二十四山使用复用的罗盘脚本，支持测量误差与磁北/真北/网格北。临近分界的测量不能强行归为高精度结论。

```bash
python "<skill-dir>/scripts/luopan.py" 180 --north-basis magnetic --uncertainty-degrees 2 --pretty
```

`minggua.py` 是上游简化个人命卦工具，年份及性别口径见其 `--help` 和输出说明。只有用户希望结合命卦时才收集相关信息，立春附近等历法边界需要额外核验，不能把简化年份算法当完整生辰排盘。

`bazhai.py` 提供八宅游年与立春年界命卦：由坐山定宅卦、翻卦得八方九星（四吉生气/天医/延年/伏位，四凶祸害/六煞/五鬼/绝命），可叠加命卦判断命宅相配。

```bash
python "<skill-dir>/scripts/bazhai.py" --sit 子 --birth 1988 --gender 男 --json
```

## 三元玄空

记录建成或大修年份、是否按入住时间定运、房屋坐向角、参考北、测量误差、流派及是否涉及兼向替卦。家具与房间可用于空间定位，宅盘本身还需要可信计算来源。

复用 `periods.py` 计算 1864–2043 年的三元运数。`flying_stars.py` 只生成以运数入中的基础洛书顺逆飞布。其 `--year` 用年份查元运，输出应保留该说明。

`xuankong.py` 提供玄空飞星下卦排盘：给定运与坐山，输出运/山/向三盘逐宫星与旺山旺向、上山下水、双星到向/到坐格局，坐向可用 `--sit` 山名或 `--facing`/`--sitting` 度数（偏离山中心超 4.5° 判兼向并显式告警）。只做下卦，兼向替卦与年/月盘仍需外部可信工具输入。

```bash
python "<skill-dir>/scripts/periods.py" 2026 --pretty
python "<skill-dir>/scripts/flying_stars.py" --period 9 --pretty
python "<skill-dir>/scripts/xuankong.py" --sit 子 --yun 8 --json
```

## 三合与外局

可讨论来龙、砂水、来去水、明堂和围合，但需要室外地形、水系、道路、建筑高差与可靠坐向。室内采集范围无法覆盖这些输入时，把结论限制在实际室内证据。仅有室内模型时，这部分列入缺项。

## 五行与材质象义

使用用户明确的材质、用途、颜色和布局事实进行象义讨论，说明依据的流派与现代解释。RGB 外观只能支持视觉描述，真实材质、反射率和构造需要另外取证。几何测量值不直接换算为统一的五行或吉凶总分。
