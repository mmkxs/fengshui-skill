# 通风与层高

## 输入与可计算内容

| 输入 | 可计算或描述 | 仍需确认 |
| --- | --- | --- |
| 房间面积与均匀净层高 | 近似房间体积 `V = A × H`，单位 m³ | 斜顶、变层高、夹层、大体积家具、有效空气体积 |
| 有限门窗平面、对外角色与开合比例 | 当前标注开口的几何面积与中心高度差 | 有效自由面积、纱窗/百叶阻力、门窗状态代表性 |
| 对外开口及已标注遮挡 | 对向法向候选、中心连线被哪些几何盒阻挡 | 室内实际流动路径、周围建筑、完整墙体与室内门状态 |
| 实测室外通风量 `Q` | 在给定体积模型下计算 `ACH = Q / V` | 测量工况、风量平衡、混合程度与室外新风占比 |
| 模拟或设定风量 | 对应 simulated/scenario 条件下的 Q/V | 模型边界与验证，实际运行数据 |

脚本中的 `openFraction` 表示可通几何面积比例。对外开口法向应朝室外。对向阈值 `normalDot ≤ -0.5` 是筛查约定，用于标记开口朝向关系。高低开口只记录中心高差。

## 影响机制

在相同室外通风量 Q 下，净层高增大使体积 V 增大，因此换气次数 ACH 减小。在相同几何条件下，风、室内外温差、有效开口面积、位置、阻力和设备状态又会影响实际 Q。高空间是否形成热浮力驱动，还取决于真实高低开口、温差和压力分布。

层高本身不能推出通风量、风速、污染物浓度或舒适度。高低开口差也不能直接当作房间净层高。风向不等于室内气流路径，门窗中心线畅通不等于流量已确认。

风量字段须记录来源。

```json
{
  "ventilation": {
    "flowM3h": 120,
    "basis": "scenario",
    "evidenceRef": "用户提供的对比工况，非实测"
  }
}
```

`basis` 支持 measured、simulated、scenario。设备铭牌风量、循环风、排风和有效室外送风的含义分别核对后再使用。脚本不根据固定住宅层高或 ACH 阈值输出健康、规范合格或吉凶判定。

需要真实流场时，由适当工具处理风压、热浮力、开口阻力和设备边界，或提供可核验的现场测量。把工具、网格/模型版本、天气、温度、开合状态、流量与误差记录到证据中。
